# Task 22 - Image Carousel / Slider

## 📌 Project Overview

This project is an **Image Carousel/Slider** developed as part of the Veda Technology Web Development Internship.

The carousel displays multiple images with manual navigation controls, automatic slide rotation, hover pause functionality, and slide indicators.

## 🎯 Objective

To practice:

- DOM indexing
- JavaScript timers
- CSS transitions
- Event handling
- Responsive web design

## ✨ Features

- 5 different image slides
- Next and Previous navigation buttons
- Automatic slide rotation
- Auto-rotation pauses when the mouse hovers over the carousel
- Slide indicators for direct navigation
- Automatic timer restarts after manual navigation
- Smooth CSS transitions
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
