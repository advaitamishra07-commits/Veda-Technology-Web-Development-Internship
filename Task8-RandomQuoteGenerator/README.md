# Task 8 - Random Quote Generator

A modern and responsive Random Quote Generator developed for the Veda Technology Web Development Internship.

## Project Description

The Random Quote Generator displays a randomly selected inspirational quote along with its author whenever the user clicks the New Quote button.

## Features

- 30 inspirational quotes
- Quotes stored as JavaScript objects
- Random quote selection using Math.random()
- Prevents the same quote from appearing twice consecutively
- Displays quote and author dynamically
- Share button
- Clipboard fallback for unsupported browsers
- Responsive design
- Modern dark user interface
- Smooth quote animation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works
Quotes are stored in an array of JavaScript objects.
Each object contains a quote and its author.
Math.random() generates a random index.
The selected quote is displayed on the webpage.
The application checks the previous index to prevent consecutive duplicate quotes.
The Share button allows users to share or copy the current quote.
