# Digital Clock

A simple and responsive digital clock built using HTML, CSS, and JavaScript.

## Features

- Displays the current time in HH:MM:SS format
- Automatically updates every second
- Adds leading zeros to single-digit values
- Displays the current date
- Responsive design for different screen sizes
- Modern blue and purple gradient interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The JavaScript `Date` object is used to get the current time and date.

The `setInterval()` function updates the clock every second.

The `padStart()` method adds leading zeros to hours, minutes, and seconds when required.
