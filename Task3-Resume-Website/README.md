# Personal Resume Website

A responsive single-page resume website created as part of my Web Development Internship at Veda Technology.

## Project Overview

This project presents my academic background, technical skills, internship experience, projects, and contact information in a modern, responsive resume website.

The website uses a dark theme with red and blue accents to create a clean and professional developer portfolio.

## Features

- Responsive single-page layout
- Profile section
- Education section
- Technical skills section
- Internship experience section
- Projects section
- Contact section
- Clickable Email, GitHub, and LinkedIn links
- Responsive navigation
- Mobile-friendly design
- Hover effects and visual transitions

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Tools Used

- Visual Studio Code
- Git
- GitHub
- Web Browser

## Development Approach

The website was developed using semantic HTML5 elements to organize the content into clear sections.

CSS3 was used for:

Layout and positioning
Flexbox and Grid
Responsive design
Colors and typography
Hover effects
Buttons and cards
Mobile responsiveness

No external CSS framework was used.

## Outcome

The final website provides a simple and responsive way to present my education, skills, experience, projects, and professional contact information.

## How to Run
Download or clone the repository.
Open the project folder.
Open index.html in a web browser.
Navigate through the different sections using the navigation menu.
