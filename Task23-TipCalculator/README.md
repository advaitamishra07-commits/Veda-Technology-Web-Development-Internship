# Task 22: Tip Calculator

## Project Overview

The Tip Calculator is a responsive web application developed using HTML, CSS, and JavaScript. It helps users calculate the tip amount, total bill, and cost per person when splitting a bill.

## Objectives

- Practise HTML form inputs and CSS styling.
- Perform calculations using JavaScript.
- Implement input validation.
- Update results dynamically when inputs change.
- Create a responsive and user-friendly interface.

## Features

- Bill amount input in Indian Rupees.
- Preset tip percentages: 5%, 10%, 15%, 20%, and 25%.
- Custom tip percentage input.
- Number of people input.
- Automatic tip and total calculations.
- Per-person bill splitting.
- Input validation.
- Reset calculator functionality.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Formula

Tip Amount = Bill Amount × Tip Percentage / 100

Total Bill = Bill Amount + Tip Amount

Tip Per Person = Tip Amount / Number of People

Total Per Person = Total Bill / Number of People

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Enter the bill amount.
4. Select a tip percentage or enter a custom percentage.
5. Enter the number of people.
6. View the calculated results.
