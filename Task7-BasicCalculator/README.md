# Task 7 - Basic Calculator

## Veda Technology Web Development Internship

A modern and responsive calculator built using HTML5, CSS3, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear functionality
- Equals functionality
- Divide-by-zero handling
- Keyboard support
- Responsive design
- Modern glassmorphism-style interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Learning Objectives

This project demonstrates:

- JavaScript event handling
- DOM manipulation
- Arithmetic operations
- CSS Grid layout
- Input handling
- Error handling

## Important

The calculator performs calculations using JavaScript logic and does not use `eval()`.
