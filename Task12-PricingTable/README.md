# Task 12 - Pricing Table

## 📌 Project Overview

This project is a responsive pricing table created using HTML5 and CSS3 as part of the Veda Technology Web Development Internship.

The pricing table contains three different plans with features, pricing, call-to-action buttons, hover effects, and responsive design.

## ✨ Features

- Three pricing plans
- Basic, Pro, and Premium plans
- Highlighted Pro plan
- Feature comparison
- Interactive buttons
- Hover effects
- Responsive design
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3

🚀 How to Run
Download or clone the repository.
Open the Task12-PricingTable folder.
Open index.html in a web browser.
