# Task 4 - Countdown Timer

## Veda Technology Web Development Internship

A responsive countdown timer built using HTML, CSS, and JavaScript. The application counts down to a specified target date and displays the remaining days, hours, minutes, and seconds in real time.

## Features

- Real-time countdown updated every second
- Displays remaining days, hours, minutes, and seconds
- Configurable target date
- Automatically stops when the countdown reaches zero
- Displays a completion message when the countdown ends
- Responsive design for desktop, tablet, and mobile devices
- Modern card-based user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
