# Task 19 - Star Rating Widget

## Description

A simple interactive Star Rating Widget developed using HTML, CSS, and JavaScript.

Users can click on any of the five stars to select a rating from 1 to 5.

## Features

- 5 clickable stars
- Hover preview effect
- Selected rating stored in JavaScript state
- Dynamic star highlighting
- Displays the current rating
- Responsive and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Five stars are displayed on the screen.
2. Hovering over a star previews the rating.
3. Clicking a star selects the rating.
4. The selected rating remains highlighted.
5. The current rating is displayed below the stars.
