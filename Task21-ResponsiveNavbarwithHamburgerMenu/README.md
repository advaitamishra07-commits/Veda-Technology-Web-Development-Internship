# Task 21 - Responsive Navbar with Hamburger Menu

## Veda Technology - Web Development Internship

### Task Description

Create a responsive navigation bar that works smoothly on desktop, tablet, and mobile screen sizes. On smaller screens, the navigation links are replaced with a hamburger menu.

## Objective

The objective of this task is to understand and implement:

- Responsive web design
- CSS media queries
- Navigation menus
- JavaScript interactions
- CSS transitions and animations
- Mobile-friendly layouts

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive navigation bar
- Desktop horizontal navigation menu
- Hamburger menu for mobile devices
- Slide-in mobile navigation
- Animated hamburger icon
- Smooth menu transitions
- Sticky navigation bar
- Navigation links for different sections
- Mobile-friendly interface
