# Task 14 - Color Palette Generator

A simple and responsive Color Palette Generator developed as part of the Veda Technology Web Development Internship.

## Project Description

This project generates a random set of five HEX color swatches.

Users can generate a new palette and click on any color to copy its HEX code to the clipboard.

## Features

- Generate five random colors
- Display HEX color codes
- Generate a new palette with one click
- Copy HEX codes to clipboard
- Copy confirmation message
- Responsive design
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Used

- Math.random()
- Math.floor()
- DOM manipulation
- Event listeners
- Functions
- Clipboard API
- Dynamic element creation

## How It Works

1. Click the "Generate New Palette" button.
2. Five random HEX colors are generated.
3. Each color is displayed as a separate swatch.
4. Click any swatch to copy its HEX code.
5. A confirmation message appears after copying.
