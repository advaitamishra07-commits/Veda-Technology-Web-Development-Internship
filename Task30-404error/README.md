
# Task 30 - Custom 404 Error Page

## Description
A responsive custom 404 error page designed for the
Veda Technology Web Development Internship.

## Objective
To create a friendly error page with a clear message,
custom illustration, and a link back to the homepage.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Large and readable 404 heading
- Friendly error message
- Custom CSS illustration
- Responsive desktop and mobile layout
- Back to Homepage link
- Functional browser back button
- Hover effects and floating animation

## How to Run
1. Download the project files.
2. Keep index.html, style.css, and script.js
   in the same folder.
3. Open index.html in a web browser.

## Conclusion
This project demonstrates responsive web design,
CSS styling, animation, and basic JavaScript
navigation functionality.
