
# Task 26 - Signup Form with Validation

## Overview
A modern and responsive signup form developed using HTML5, CSS3, and JavaScript. The project validates user inputs and provides instant feedback through inline error messages.

## Features
- Full name validation
- Email format validation using regular expressions
- Password complexity validation
- Real-time password strength indicator
- Confirm password matching
- Inline error messages
- Prevents submission when inputs are invalid
- Success message for valid submissions
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Regular Expressions

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html' in a browser, or use the Live Server extension.
4. Enter the required details and test the validation.

## Validation Rules
- Name must contain at least 2 characters and use valid name characters.
- Email must follow a valid email format.
- Password must contain at least 8 characters, uppercase and lowercase letters, a number, and a special character.
- Confirm password must match the password.
- The form displays success only when all fields are valid.

## Learning Outcomes
This project helped me practice DOM manipulation, event handling, regular expressions, form validation, and user feedback.

## Note
This project demonstrates client-side validation only. It does not create or store real user accounts.
